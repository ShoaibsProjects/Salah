# Salah

**Project status:** vision and architecture proposal, September 2026. No calculation engine or application has been implemented in this repository yet.

Salah  is a proposed, free-to-use prayer-time system for Earth. Its foundation is an offline Rust calculation core with a public calculation specification. iOS, Android, web, and future interfaces can use the same core. A person should be able to obtain prayer times and a Qibla bearing without an account, paid API, or network connection.

The complete project document is [Vision and architecture](docs/vision-and-architecture.md). It covers product scope, Islamic methodology, calculation and time-zone design, privacy, validation, the first release, and the maintenance needed to keep the system useful through .

The name is a working title. Calculation methods, default regional settings, scholarly review, open-source license, and the final user interface need decisions before launch.
